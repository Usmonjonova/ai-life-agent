# Daily and Weekly Review

## Daily review

Keep it short enough that the user will actually do it.

Core questions:

1. What important thing did you complete?
2. What did you not complete?
3. What blocked you?
4. What should change tomorrow?

Optional:

- energy;
- mood;
- unexpected events.

## Weekly review

### Progress

- goal progress;
- milestone progress;
- important completed work.

### Reality check

Compare:

- planned time;
- actual time;
- planned tasks;
- completed tasks.

### Pattern detection

Look for:

- repeated postponements;
- recurring time conflicts;
- underestimated tasks;
- time-of-day patterns;
- overplanning.

### Adaptation

The agent proposes:

- fewer tasks;
- different task sizes;
- different schedule;
- changed priorities;
- new milestone;
- goal review.

The user approves significant changes.

## Important distinction

A low-completion week does not automatically mean failure.

The review should answer:

> What did we learn that can make the next plan better?
