# Product Roadmap

## Phase 0 — Specification

Goal:

Create a clear product and technical foundation.

Deliverables:

- product vision;
- user journey;
- MVP scope;
- agent rules;
- data model;
- architecture.

## Phase 1 — Telegram MVP

Build:

- Telegram bot;
- FastAPI backend;
- PostgreSQL;
- onboarding;
- goals;
- tasks;
- daily plan;
- reminders;
- reflection;
- weekly review.

Success criterion:

The builder uses the agent consistently for several weeks.

## Phase 2 — Adaptive Agent

Add:

- behavioral analytics;
- plan-vs-actual analysis;
- adaptive task sizing;
- smarter reminder behavior;
- pattern detection.

## Phase 3 — Android Companion

Add:

- Android app;
- usage statistics;
- local aggregation;
- screen-time signals.

## Phase 4 — Web Dashboard

Add:

- goal overview;
- progress;
- trends;
- behavior analytics;
- memory transparency.

## Phase 5 — Mobile Product

Add a dedicated mobile interface while retaining the same backend and agent core.

## Phase 6 — Productization

Only after personal validation:

- multi-user architecture;
- onboarding experiments;
- billing;
- analytics;
- scalable infrastructure;
- stronger security/compliance.

## Guiding rule

Do not build Phase 3–6 before Phase 1 proves that the core loop is genuinely useful.
