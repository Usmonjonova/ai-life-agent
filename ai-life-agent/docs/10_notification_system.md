# Notification System

## Objective

Remind the user without becoming another source of distraction.

## Notification types

1. Task reminder
2. Start prompt
3. Deadline warning
4. Evening reflection
5. Weekly review
6. Adaptive intervention

## Priority

Not all notifications are equal.

### High

- important deadline;
- explicitly requested reminder.

### Medium

- planned important task;
- evening review.

### Low

- optional suggestion.

## Anti-spam rules

- respect quiet hours;
- limit repeated reminders;
- detect ignored notifications;
- avoid sending multiple notifications close together;
- allow easy disable/snooze.

## Adaptive reminder example

If the user repeatedly ignores a 60-minute task:

Do not keep sending the same reminder.

Instead:

> This task has moved three times. Should we make it smaller, move it to another day, or reconsider its priority?

## Future screen-time intervention

When screen-time data becomes available, notifications should be goal-aware.

Bad:

> You used Instagram too much.

Better:

> You planned 90 minutes for your SQL project today and have completed 0 minutes. Instagram usage is already 2h10m. Want to start a 25-minute SQL focus session?

The agent should avoid moralizing about entertainment.
