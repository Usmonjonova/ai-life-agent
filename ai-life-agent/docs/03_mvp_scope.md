# MVP Scope

## MVP objective

Validate one core loop:

**User goal → realistic plan → action → reminder → reflection → adaptation**

## In scope

### 1. Telegram interface

- conversational interaction;
- basic commands;
- inline action buttons where useful.

### 2. Onboarding

Collect only information needed to create an initial useful model:

- preferred name;
- current major goals;
- why the goals matter;
- current commitments;
- approximate available time;
- preferred planning style;
- reminder preferences.

### 3. Goal management

- create goal;
- edit goal;
- archive goal;
- define why;
- define target date when relevant;
- create milestones.

### 4. Tasks

- create;
- prioritize;
- schedule;
- complete;
- skip;
- postpone;
- reschedule.

### 5. Daily plan

The agent proposes a small set of priorities rather than an exhaustive schedule.

### 6. Reminders

Reminder actions:

- Start;
- Done;
- Move;
- Skip.

### 7. Reflection

Short evening interaction:

- What was completed?
- What was not?
- Why?
- What should change tomorrow?

### 8. Weekly review

Summarize:

- progress;
- completed high-priority work;
- missed work;
- recurring obstacles;
- planning accuracy;
- recommended adjustments.

### 9. Persistent memory

Store stable and useful context while separating it from temporary conversation state.

## Explicitly out of MVP

- screen-time integration;
- calendar integrations;
- wearable integrations;
- voice interface;
- complex web dashboard;
- autonomous life decisions;
- financial/medical/legal decision-making;
- broad multi-user product optimization.

## MVP success criteria

The MVP is successful if the user voluntarily uses it for several weeks and reports that:

1. it reduces planning friction;
2. its plans feel realistic;
3. reminders help rather than annoy;
4. reflections produce useful insight;
5. the next week's plan improves based on previous evidence.
