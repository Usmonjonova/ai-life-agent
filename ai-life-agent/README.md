# AI Life Agent

An adaptive personal AI agent that helps a person turn long-term goals into realistic actions, observe actual behavior, learn from results, and continuously adapt the plan.

## Product thesis

> Planning is useful only when it survives contact with real life.

The agent is designed to close the loop:

**GOAL → PLAN → ACT → OBSERVE → ANALYZE → LEARN → ADAPT → PLAN**

## Initial interface

Telegram is the first interface because it minimizes friction. The product architecture is intentionally interface-independent so a web/mobile client can be added later.

## MVP

- Telegram conversational interface
- User onboarding
- Goals and milestones
- Tasks and daily plans
- Reminders
- Daily reflection
- Weekly review
- Persistent memory
- Basic progress analytics

## Later phases

- Adaptive planning based on behavior
- Android screen-time integration
- Calendar integration
- Web dashboard
- Mobile application
- Additional personal data sources

## Guiding principles

1. AI supports autonomy; it does not replace decision-making.
2. Plans must be realistic, not maximally ambitious.
3. The agent should learn from behavior, not only stated preferences.
4. Notifications should be useful and sparse.
5. The user should be able to understand what the agent knows and why it recommends something.
6. Privacy is a product requirement, not an afterthought.
